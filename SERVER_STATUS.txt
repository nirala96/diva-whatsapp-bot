================================================================================
🆘 TROUBLESHOOTING
================================================================================

"OpenAI API key not valid" or "Authentication failed":
→ Check your API key in .env file
→ Make sure it starts with "sk-"
→ Verify you have credits in your OpenAI account

"Connection refused" or "Cannot connect":
→ Check if server is running: curl http://localhost:8000/
→ If not running, start it with the command above

"Google Sheets error":
→ This is optional - bot will still work for chat
→ If you want logging, follow GOOGLE_SHEETS_SETUP.md

Server crashed or not responding:
→ Check the server logs
→ Kill and restart the server
→ Make sure port 8000 is not in use by another app
